# Chenyu Du — Academic Homepage

Personal academic homepage: https://yuuu-05.github.io/

Static HTML, CSS, and a small progressive-enhancement script. Open index.html locally. GitHub Pages serves main from the repository root. No build dependencies or tracking scripts.

## Content and layout

Compact biography and publication rows with figures on the left and text on the right, informed by https://wumuzhe.com/ . Original code; no copied third-party personal assets. No personal portrait. Mobile layout uses a single column.

Only accepted or published work receives paper entries, images, and links. Work under review is represented by broad interests only. Do not publish its titles, author lists, figures, methods, results, PDFs, or videos before acceptance without explicit instruction from the owner.

CV is available by email until a public version has been reviewed for unpublished research details.

## Updating

Edit index.html for content, styles.css for appearance. Store approved public images in assets/ and documents in files/. Review the entire file tree, including unlinked assets, before deployment. Preserve accurate authorship and publication status.
